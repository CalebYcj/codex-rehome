# Contributing

Codex ReHome is an open-source beta. Bug reports are welcome when they include the app version, operating systems, a redacted error message, and the migration direction. Never attach a personal `.rehome` file, token, conversation export, or private project to a public issue.

For changes, keep Desktop behavior, package compatibility, and safety checks covered by focused tests. Do not weaken default exclusions for authentication data, secrets, browser state, or runtime files.
