# Security

Do not publish a personal `.rehome` migration package. It can contain private conversation history, project files, local paths, and generated artifacts.

ReHome Desktop excludes authentication data, cookies, `.env` files, private keys, `.git`, `node_modules`, virtual environments, and runtime files by default. If you discover an unintended inclusion path or security issue, report it privately to the repository owner. Do not attach a personal package to a public issue.
